# Island 1.2.10 с открытым Pro

Выкладываю пропатченную сборку Island 1.2.10 — это «островок» вверху экрана для Windows,
у которого Pro обычно стоит 399 ₽. Тут Pro включён всегда, проверка ключа отключена,
ключ покупать не надо.

Делал для себя, выкладываю как есть. Версия 1.2.10, больше ничего не менял.

## Как поставить

С нуля:

1. Создать папку `%LOCALAPPDATA%\Island` (Win+R → вставить путь → Enter, если папки нет).
2. Кинуть туда `island.exe` из архива.
3. Запустить его.

Если Island уже стоит официальный — проще так:

1. Закрыть его (трей → правый клик → «Выйти»), на всякий случай проверить в диспетчере задач.
2. Запустить `patch.bat`.
3. Запустить Island.

`patch.bat` сам найдёт установленный `island.exe`, сверит байты на нужных местах
и правит их. Если файл уже пропатчен — скажет, что делать нечего.
Если версия другая и байты не совпали — тоже скажет и ничего не испортит.
Рядом с ним `patch.ps1` — сам код, bat только чтобы запускалось двойным кликом.

## Что правится

Два места в коде, оба в `island.exe` (смещения считаются от начала файла):

- `0x168FED`, 6 байт `0F 85 92 00 00 00` → `90×6` — ветка «подпись ключа не сошлась»
  становится недостижимой, подпись не проверяется.
- `0x168B1B`, 7 байт `84 DB 74 44 0F B6 C3` → `31 C0 90 90 90 90 90` — функция статуса
  лицензии всегда уходит в ветку «ключ есть», флаг `pro` выставляется в true.

Второго патча достаточно и без ключа, поэтому вводить ничего не нужно.
Первый оставил на случай, если кто-то захочет вписать ключ в настройках.

## Про обновления

Island умеет обновляться сам, через GitHub. После обновления патч слетает и Pro пропадает,
но приложение продолжает работать как бесплатное. Лечится повторным `patch.bat` — если
автор не менял эти места в новой версии. Если поменял, bat скажет, что байты не совпали.

Совет: в настройках → «Обновления» галочку «проверять обновления» лучше снять,
пока сидишь на 1.2.10.

## Что даёт Pro

Все 25 персонажей, погода с прогнозом, чат с ИИ и диктовка (нужен свой ключ любого
ИИ-сервиса, например бесплатный Groq), запись экрана, распознавание текста с экрана,
статус агентов Claude Code / Codex / opencode.

## Чем собирал

7-Zip по установщику, дальше руками в дизассемблере: в бинаре нашлись строки
`это не ключ Island Pro` и разбор ключа `ISL1-` + base64url от XOR-0x5A, с проверкой
подписи Ed25519 и публичным ключом по `0x1409C631A`. Оттуда и оба патча.

Ключ, если интересно, собирается так:

```
payload = 01 00 | serial(4, BE) | 00 00 | 72-байтная подпись
key     = "ISL1-" + base64url(payload XOR 0x5A)
```

Сам файл лежит в архиве только потому, что так ставится без интернета. Хэш оригинала
`Island_1.2.10_x64-setup.exe`: `8466e5f2c7fd9588ae832cf1af84fa179a5ecb0aad91d4108fc95b6a22303ee9`,
если понадобится сверить, что за база.

Только Windows 10/11 x64. Права администратора не нужны.
