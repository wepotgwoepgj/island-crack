# Island 1.2.11 с открытым Pro

Пропатченная сборка Island 1.2.11 — «островок» вверху экрана для Windows, у которого Pro
обычно стоит 399 ₽. Тут Pro включён всегда, проверка ключа отключена, ключ покупать не надо.

Делал для себя, выкладываю как есть. Версия 1.2.11, больше ничего не менял.

## Как поставить

С нуля:

1. Создать папку `%LOCALAPPDATA%\Island` (Win+R → вставить путь → Enter, если папки нет).
2. Кинуть туда `island.exe` из архива.
3. Запустить его.

Если Island уже стоит официальный (любой версии) — так:

1. Закрыть его (трей → правый клик → «Выйти»), на всякий случай проверить в диспетчере задач.
2. Запустить `patch.bat`.
3. Запустить Island.

`patch.bat` сам найдёт установленный `island.exe`, сверит байты и правит их.
Уже пропатченный файл он не тронет. Если версия другая — попробует найти места по коду,
а если не выйдет, скажет, что не совпало, и ничего не испортит.

Рядом с ним `patch.ps1` — сам код, bat только чтобы запускалось двойным кликом.

## Что правится

Два места в коде `island.exe`:

- проверка подписи ключа: ветка «подпись не сошлась» отключается совсем;
- функция статуса лицензии: всегда уходит в ветку «ключ есть», флаг `pro` ставится в true.

Второго хватает и без ключа, поэтому вводить ничего не нужно. Первый оставил на случай,
если кто-то захочет вписать ключ в настройках.

Смещения, которые проверены руками (для 1.2.11):

```
0x180F39, 6 байт 0F 84 C8 00 00 00 → E9 C8 00 00 00 90
0x180547, 7 байт 84 DB 74 44 0F B6 C3 → 31 C0 90 90 90 90 90
```

Для 1.2.10 это `0x168FED` (там `0F 85 …` → `90×6`) и `0x168B1B` (те же 7 байт).
Скрипт сам выбирает набор по версии файла.

## Про обновления

Island обновляется сам, через GitHub. После обновления патч слетает и Pro пропадает,
приложение при этом продолжает работать как бесплатное. Лечится повторным `patch.bat`
на новой версии — скрипт попробует найти места сам.

Если Pro не нужен, а обновления нужны — можно оставить как есть и просто не патчить.

## Что даёт Pro

Все персонажи, в том числе новогодние, погода и несколько городов, чат с ИИ (ChatGPT,
Gemini, DeepSeek) и диктовка, запись экрана, распознавание текста с экрана, голосовая
команда, статус агентов Claude Code / Codex / opencode.

## Про ключ

Формат ключа, если интересно:

```
payload = 01 00 | serial(4, BE) | 00 00 | 64 байта подписи
key     = "ISL1-" + base64url(payload XOR 0x5A)
```

Проверка локальная, Ed25519, публичный ключ вшит в бинарь (в 1.2.11 лежит по `0x140B34730`, в 1.2.10 был другой).

Оригинальный установщик, с которого снят файл:
`Island_1.2.11_x64-setup.exe`, SHA-256 `28f04f7b753e6ad5d73116c68103b1612c09fe242a4159d2ee5f8e8272045662`.

Только Windows 10/11 x64. Права администратора не нужны.
